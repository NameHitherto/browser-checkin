# ECY Cloud 签到流程修复

设计日期：2026-10-28。范围限于 ECY 适配器及其回归测试、构建产物，不改变其他站点和个人配置。

## 依据与问题

用户手动验证的顺序为关闭提示弹窗，然后点击签到入口：

1. 关闭：`/html/body/main[2]/div/section/div[4]/div/div/div[2]/p/button`
2. 签到区域：`/html/body/main[2]/div/section/div[1]/div[3]/div[1]/div[2]/div[2]/div[6]/div`

2026-10-28 实时读取官网公开 `theme/material/js/user.index.js?v=1792149483`：页面在 jQuery ready 中初始化公告并绑定 `#checkin`；签到成功后将 `#checkin-btn` 改为“今日已签到”。公告关闭后还可能接着出现 `#result` 提示。旧实现直接 POST，既未关闭提示，也因无法读取验证码开关而提前停止。

## 决策与状态契约

- 使用适配器私有 XPath 常量；签到区域若包含 `#checkin`，点击子按钮以触发官网处理器。保留官网 `#checkin` / `#checkin-btn` 语义定位，以适应布局索引变化；不扫描和点击无关按钮。
- 等待页面 `readyState=complete` 并至少留出一次初始化稳定期；每次弹窗处理后重新查找元素。页面准备和弹窗处理合计最多 35 秒，结果等待最多 25 秒，适配批量任务 90 秒预算。
- 仅关闭用户提供的按钮和已确认的官网提示弹窗关闭控件；每个关闭控件最多点击一次。确认提示、遮罩已消失且稳定后才允许签到；无法关闭的弹窗返回 `manual`。
- 开始已签返回 `already`；点击一次后官网签到区域明确已签才返回 `success`；不将点击、弹窗消失、普通成功文案当作签到完成。
- 登录路径返回 `login`；官网要求人机验证或限流返回 `manual`；明确签到错误返回 `failed`；单次点击后未确认结果返回 `unknown`，不重复点击或降级 POST。
- 官网处理会话及动态参数。适配器不读取、复制、记录验证码答案、Cookie、Token 或原始响应。验证码配置缺失不阻止官网正常处理；遇到实际人工验证停止。
