# 实现与发布约束

1. 认证只在真实浏览器、对应网站页面中读取；不在 GitHub、脚本存储、日志、构建产物中存放认证凭证。
2. 保留已有脚本 name、namespace、storageName，升级不创建重名执行器或丢弃个人设置。
3. 单一站点注册表生成页面匹配、运行列表、配置定义；网站逻辑各自独立，新增只修改注册表并增加适配器。
4. 禁用站点必须同时禁止自动访问签到、手动全签及定时签到；个人设置与发布代码分开。
5. 不在后台直接复制/读取浏览器凭证。页面执行器同源执行；库库通过官网按钮生成动态参数。
6. 成功以服务器状态复核或官网明确已签状态为准；遇验证码、错误、未知结果不循环提交。
7. GitHub 只接收源码、构建结果、合成测试、公开接口说明。原始抓包、账号页面、个人路径与运行日志不纳入仓库。
8. 推送订阅的 main 分支仅放通过测试的代码；提高脚本和订阅版本，提供 Git tag 与 Release 以便审计与回滚。
9. 本项目仅在用户明确选择公开仓库后发布；公开内容不包含凭证和用户运行数据。
10. 离线模拟、GitHub CI、公开更新链接可用性与真实账号签到验收分别报告。
